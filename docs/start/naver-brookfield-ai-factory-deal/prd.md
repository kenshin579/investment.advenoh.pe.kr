# 네이버-브룩필드 AI 팩토리 딜 — 투자 리서치 PRD

작성일: 2026-08-16

## 1. 개요

### 1.1 목적

2026년 7월 27일 발표된 네이버-엔비디아-브룩필드 3자 AI 팩토리 딜을 해부하고, **네이버 주주와 브룩필드 주주 각각의 관점에서** 이 딜이 무엇을 의미하는지 정리한다.

최종 산출물은 "이 딜을 근거로 두 종목의 비중을 언제 어떻게 조절할지" 판단할 수 있는 리서치 메모다.

### 1.2 배경

- 네이버와 브룩필드는 지분 관계가 아니라 **인프라 금융 파트너십**으로 묶여 있다. 같은 딜에서 양쪽 주주가 얻는 것과 지는 리스크가 완전히 비대칭이다
- "브룩필드 주주"라는 표현 자체가 모호하다. BN / BAM / BIP / BEP 중 어느 상장 엔티티가 이 딜의 리스크와 수익을 지느냐에 따라 주주 영향이 전혀 다르다
- 국내 보도의 "유상증자 + PF 14.6조 조달"이 사실이면 네이버 주주에게는 희석 이슈가 중기 판단의 핵심이 된다

### 1.3 조사자 전제

이 메모는 특정 포지션을 전제로 작성한다.

| 항목 | 내용 |
|------|------|
| 보유 종목 | 네이버, 브룩필드 (둘 다 보유) |
| 투자 기간 | 중기 6개월 ~ 2년 |
| 목적 | 신규 진입이 아니라 **비중 조절** |
| 핵심 질문 | 희석·조달 부담 대비 성장의 순효과는? 브룩필드 쪽은 주가에 반영될 만한 딜인가? |

중기 관점이므로 2028년 완공·1GW 로드맵보다 **유상증자 희석률, 손익 반영 시점, 리레이팅 여부**에 무게를 둔다.

### 3.2 리서치 메모 목차

**1장. 딜 개요**
1차 출처 기준으로 사실관계와 숫자를 확정한다. 3자의 역할 분담.

**2장. 자금 구조 해부** — 이 조사의 핵심
- 2.1 SPV 소유·출자 구조, 컴퓨팅 사용료 계약 형태
- 2.2 네이버 부담의 실체 — "유상증자 + PF 14.6조" 보도 검증, 희석률 계산
- 2.3 브룩필드 90억 달러의 출처 엔티티 규명 (BN / BAM / BIP / 사모 BIF 펀드)

**3장. 네이버 주주 관점**
- 3.1 손익 반영 경로와 시점 — 사용료는 비용, AI 매출은 언제부터
- 3.2 "연매출 14조" 추정치의 근거와 신뢰도
- 3.3 희석 vs 성장의 순효과 (6~24개월 기준)
- 3.4 리스크 — 수요 미달 시 take-or-pay 여부, 엔비디아 하드웨어 사이클, 전력·인허가

**4장. 브룩필드 주주 관점**
- 4.1 실제 수혜 엔티티 규명
- 4.2 수수료 수익 vs 자기자본 수익 구조
- 4.3 브룩필드 전체 AI 인프라 파이프라인 대비 이 딜의 비중 = 주가 영향의 크기
- 4.4 리스크 — 자산 집중, 금리, 한국 규제·전력

**5장. 관계의 비대칭**
같은 딜에서 양쪽이 얻는 것과 지는 것을 한 장 비교표로.

**6장. 시나리오와 트리거 (6~24개월)**
- 베이스 / 불 / 베어 3안
- 이벤트 캘린더 — 증자 공시, 분기 실적, 착공·가동 마일스톤
- 비중 조절 트리거 표 — 메모의 실질적 결론

**7장. 미확인 항목과 추가 확인 방법**
공개 자료로 밝히지 못한 것을 명시적으로 남긴다. 향후 공시가 나오면 이 장부터 채운다.

**8장. 출처**
전 항목 URL. 등급 표기 포함.

**부록. 블로그 전환 시 남길 것 / 뺄 것**
개인 포지션·트리거는 제외하고 2·4·5장이 글감이 된다.

## 4. 조사 방법

### 4.1 출처 등급

보도와 추정이 섞여 있어 등급을 구분하지 않으면 메모가 쓸모없어진다. 본문 각 주장에 등급을 표기한다.

| 등급 | 출처 | 표기 |
|------|------|------|
| 1차 | 네이버 보도자료, NVIDIA Newsroom, GlobeNewswire·PR Newswire 원문, DART 공시, 브룩필드 IR·분기보고서 | 확정 |
| 2차 | 뉴시스·블로터·글로벌이코노믹 등 국내 보도, The Logic 등 해외 매체 | 보도 |
| 3차 | 증권사 리포트 인용, 매체 자체 추정 | 추정 |

3차는 반드시 "추정" 표기와 근거를 함께 적는다. 특히 2.3(브룩필드 자금 출처)과 3.2(연매출 14조)는 3차로 끝날 가능성이 높다.

**추정을 사실처럼 쓰지 않는다.** 확인 실패는 7장에 실패로 기록한다.

### 4.2 검색 대상

- 국내: 네이버 보도자료, DART 공시, 국내 경제지 딜 해부 기사
- 해외: NVIDIA Newsroom, GlobeNewswire, PR Newswire, 브룩필드 IR·프레스, 데이터센터 전문지
- 재무: 네이버 분기보고서, BN·BAM·BIP 분기 실적 자료 및 컨퍼런스콜

프로젝트 규칙상 ASCII art 를 쓰지 않고 Mermaid 로 작성한다.

| 자금 조달 스택 — 90억 / 10억 / 네이버 몫 | `pie` | 2.2 |
| 브룩필드 엔티티 계층도 — BN → BAM·BIP·BEP 중 이 딜의 위치 | `graph TD` | 4.1 |
| 네이버 손익 반영 경로 — 사용료(비용) vs AI 매출(수익)의 시점 차이 | `graph LR` | 3.1 |

노드 라벨에 `%`, `~`, `/`, 괄호가 들어가면 쌍따옴표로 감싼다. 이모지는 쓰지 않는다.

## 6. 완료 기준

- [ ] 모든 3차 출처 주장에 "추정" 표기가 있다
