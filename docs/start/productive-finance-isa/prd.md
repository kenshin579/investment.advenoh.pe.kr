# PRD: 생산적금융 ISA 이해 가이드

- 작성일: 2026-08-18

- 시리즈: 연금저축 절세 전략 (3편)

## 1. 목적

2026년 7월 31일 발표된 2026 세제개편안에 신설된 **생산적금융 ISA**의 구조를 이해해두는 글이다.

> 2027년에 생산적금융 ISA가 시행됐을 때 당황하지 않도록, 지금 그 구조를 이해해두는 것

핵심은 **이해**다. 아직 국회를 통과하지 않은 정부안이므로 "지금 뭘 하라"는 실전 가이드는 쓰지 않는다.

## 2. 이 글이 하지 않는 것

브레인스토밍 과정에서 명시적으로 제외한 항목이다.

| 제외 항목 | 이유 |
|-----------|------|
| 세금 시뮬레이션 (숫자 계산) | 시행령 미확정. 정교하게 짤수록 틀릴 위험이 커진다 |
| 연도별 액션 플랜 (2026 → 2027 → 2029) | 확정 전 제도에 행동을 지시하면 글의 유통기한이 짧아진다 |
| 계좌 개설/이전 실무 절차 | 시행 전이라 절차 자체가 존재하지 않는다 |
| 인터랙티브 퀴즈 | 내용 절반이 미확정. 한도·기간이 바뀌면 정답부터 틀린 글이 된다 |

## 3. 기준 독자

**메인**: 기존 ISA를 보유하고 국내외 자산을 섞어 굴리는 30~40대 직장인. 국내 상장 미국 ETF(S&P500 등)를 ISA에 담고 있어 이번 개편의 영향을 크게 받는 층이다.

**분기로 다룰 독자**: 국내 배당주 중심 투자자, ISA를 아직 만들지 않은 사람. 6장에서 구조적 유불리로만 언급한다.

## 6. 섹션별 의도

### 3.3절이 이 글의 중심이다

"이자·배당소득 전액 비과세"라는 문구를 그대로 옮기면 독자가 오해한다. **국내 상장주식 매매차익은 원래 비과세**이므로, 개별 국내주식만 담는 투자자에게 이 혜택이 작동하는 지점은 배당금뿐이다.

혜택이 실제로 크게 작동하는 대상:
- 국내 배당주의 배당금 (15.4% 원천징수 → 0)
- 국내 상장 ETF·펀드의 분배금과 매매차익 (배당소득으로 과세되던 것이 통째로 비과세)
- 금융소득종합과세(연 2,000만원) 계산에서 제외

### 6장은 유불리 구조까지만

"이래서 유리하다 / 불리하다"에서 멈춘다. 판단은 독자에게 넘긴다. 액션 제안을 넣지 않는다.

### 2.2절에 2024년 전례를 붙인다

2024년 개편안에 이미 **국내투자형 ISA**(국내 상장주식·주식형 펀드 한정, 세율 인하, 금융소득종합과세 대상자 가입 허용)가 들어 있었다. 통과되지 않았지만 문제의식은 이번과 같다. 2024년 안이 "세율을 낮춘다"였다면 이번은 "비과세한다"이고, 대신 투자 대상 제한은 더 촘촘해졌다.

뉴스가 다루지 않는 연결이고, 자사 글 자산을 활용하는 지점이다.

### 7장이 차별점이다

확정된 것과 미확정을 갈라주는 섹션. 뉴스가 다루지 않는 부분이고, 국회 통과 후에는 이 장만 고치면 글 전체가 유효하다.

## 7. 다이어그램

3장에 Mermaid 1개. 세제 혜택이 자금을 국내 생산적 자산으로 유도하는 구조.

프로젝트 규칙에 따라 ASCII art를 쓰지 않는다. 노드 라벨에 `%`, `~`, `/`, `(`, `)`가 들어가면 쌍따옴표로 감싼다.

그 외 정보는 표로 처리한다.

## 8. 확정 사실 (본문 근거)

2026 세제개편안(2026-07-31 발표) 기준. 국회 심의 전 정부안이다.

### 생산적금융 ISA

| 항목 | 내용 |
|------|------|
| 납입한도 | 연 2,000만원 / 총 2억원 |
| 계약기간 | 최소 3년, 3년 단위 연장, 최대 10년 |
| 비과세 | 이자·배당소득 전액 (한도 없음), 농어촌특별세도 비과세 |
| 투자대상 | 국내 상장주식, 국내 주식형 펀드·ETF, 국민성장펀드, BDC |
| 가입대상 | 19세 이상 거주자, 15세 이상 근로자. 직전 3개 과세기간 중 1회 이상 금융소득종합과세 대상자는 제외 |
| 계좌 수 | 1인 1계좌. 기존 ISA와 중복 보유 가능 |
| 추징 | 3년 내 원금 초과 인출 시 해지로 간주, 비과세분 소득세 추징 |
| 시행 | 2027-01-01 이후 신규 가입분. 2029-12-31까지 가입 |

### 청년형 생산적금융 ISA

| 항목 | 내용 |
|------|------|
| 대상 | 15~34세, 총급여 7,500만원 이하 (종합소득금액 6,300만원 이하) |
| 추가 혜택 | 납입액의 10% 소득공제 (연 2,000만원 납입 시 연 200만원) |
| 추징 | 중도해지 시 비과세분 + 소득공제분 회수 |
| 자금 이전 | 청년 일반 ISA, 청년미래적금, 청년도약계좌 만기자금 이전 허용 |

### 연금계좌 전환

- 연금계좌 1,800만원 한도와 별개로 추가납입 가능
- 전환금의 10%를 세액공제 추가한도로 인정. 기존 ISA 전환분과 합산해 상한 300만원

### 기존 ISA 변경

| 항목 | 현행 | 개정안 |
|------|------|--------|
| 계약기간 | 3년 후 무제한 연장 | 총 5년까지만 |
| 연간 납입한도 | 2,000만원 × (1 + 경과연수) − 누적액 | 연 2,000만원, 이월 없음 |
| 총 납입한도 | 1억원 | 1억원 (동일) |
| 비과세 | 일반형 200만원 / 서민형 400만원 | 동일 |
| 일몰 | 없음 | 2029-12-31 |

## 9. 미확정 사항 (7장 근거)

- 국회 심의 결과 (한도·기간·대상이 바뀔 수 있음)
- 중개형 / 신탁형 / 일임형 구분 여부
- 손익통산 방식 (기존 ISA와 동일하게 계좌 내 통산일 것으로 예상되나 시행령 미공개)
- 중도인출 세부 규정 (3년 내 원금 초과 인출 시 추징만 발표됨)
- 국민성장펀드·BDC의 구체적 상품 라인업

## 10. 논란 지점 (7.3절 근거)

- 국내 상장 해외 ETF(S&P500, 나스닥100 등) 투자 불가. "절세계좌를 국내 주식 전용으로 만들었다"는 반응
- 예금·적금 불가. 안전자산 파킹 용도로 쓸 수 없음
- 연 4,000만원(두 계좌 합산)을 채울 수 있는 투자자가 제한적이라 실효성 논란
- 국내 상장주식 매매차익은 이미 비과세인데 국내 전용 비과세 계좌를 따로 만든 것에 대한 의문

- 단정적 투자 권유를 하지 않는다
